# Glosario

> Vigente · Dueño: Pp · Revisado el 28 sep 2026

| Término | Qué significa en CECAPI |
| --- | --- |
| ADR | Registro de decisión: un archivo por decisión, con su porqué. Están en `docs/decisiones/` |
| AGP | Android Gradle Plugin, la pieza que compila la app. Está congelado en 8.5.2 |
| ARCO | Derechos de Acceso, Rectificación, Cancelación y Oposición sobre los datos personales (ley mexicana) |
| Barge-in | Interrumpir a la app mientras habla: si la persona habla encima, la voz se calla |
| Caché | Archivos temporales que la app puede borrar sin perder nada |
| Cerebro temporal | Papel de la IA: traduce frases que la app no entiende a comandos que sí conoce. Está apagada |
| Comando global | Frase que funciona en cualquier pantalla (hora, volumen, pantalla negra...) |
| Coincidencia difusa | Aceptar una palabra aunque venga con una letra de más o de menos ("isquierda") |
| HRTF | Función que simula de dónde viene un sonido (izquierda, enfrente, atrás) con audífonos |
| Intercepción de comandos | Los comandos globales se atienden antes de que la frase llegue a la pantalla |
| Migración | Paso que actualiza la base de datos de una versión a otra sin perder los datos |
| Modo silencio | Tras "silencio", la app calla pero sigue escuchando "hola" |
| Modo detenido | Tras "para", la app no hace nada hasta que se vuelve a abrir |
| OCR | Reconocer el texto de una foto. Lo hace ML Kit en el teléfono |
| Palabra de activación (wake word) | "Hola", o el nombre que la persona le pone al asistente, para que empiece a escuchar |
| Selector de fotos | Pantalla de Android para elegir una imagen sin darle a la app acceso a toda la galería |
| Servicio en primer plano | Parte de la app que sigue funcionando fuera de ella, con un aviso fijo visible |
